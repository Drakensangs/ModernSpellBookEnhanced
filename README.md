# 📖 **ModernSpellBookEnhanced** (Vanilla 1.12.1)

> [!IMPORTANT]
> **ModernSpellBook Enhanced** requires [**ClassicAPI**](https://github.com/brues-code/ClassicAPI) in order to function.
> 

[**vegeta1k95**](https://github.com/vegeta1k95)'s [**ModernSpellBook**](https://github.com/vegeta1k95/ModernSpellBook) with the following enhancements/changes/additions:

 - overhauled look
 - one page view option
 - quest reward spells & book learned spells information
 - reduced savedvariable size thanks to ClassicAPI
 - cooldown numbers on spells in the spellbook
 - toggleable class colored bookmarks
 - unlearned spells show how much they cost to train
 - option to highlight spells not on the action bar
 - spell/talent level requirements are listed as green if the character's level meets the requirement
 - paginated upcoming spells frame to avoid them from clipping into spell school titles
 - profession tab is on its own page now
 - all profession passives, spells and specializations are listed under the profession tab
 - button to resize the spellbook added on the lower right
 - option to lock the position and scale of the spellbook
 - [**Clique**](https://github.com/kxseven/Clique) support
